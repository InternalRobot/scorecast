Pacific briefing / methodology

Data & sources

What feeds each surf condition, how the dashboard turns those inputs into a read, and which figures are still illustrative.

Overall score

Surf-fit index / 100

A weighted fit score based on the current primary swell. Direction contributes 55% (best match against the spot’s preferred bearings, falling linearly to zero at a 90° difference and becoming negative beyond that); period contributes 20% (scaled from 8–18 seconds); swell height contributes 15% (scaled to 5 ft); and season contributes 10% (1.0 in the preferred months, 0.72 otherwise).

This is a comparative heuristic, not a probability or a measured quality score.

Consistency

Derived percentage

Calculated as clamp(round(mean primary swell height ÷ peak wave height × 100 + 35), 50, 93) from the next 24 hourly values. It is a compact consistency proxy, not the literal percentage of forecast hours that meet a condition.

Inputs: Open-Meteo Marine API documentation.

Energy

Relative index

Calculated as round(mean primary swell height in ft × mean primary swell period in seconds × 2.3) over the next 24 hours. It is an uncalibrated comparison index, not a physical energy measurement.

Inputs: Open-Meteo Marine API documentation.

Waves & swell

Forecast model

Wave height, primary and secondary swell heights, directions, and periods come from Open-Meteo’s Marine API for each spot. Heights arrive in meters and are converted to feet. The overview’s wave range is the minimum-to-maximum wave height over the next 24 hours; swell rows show the first forecast hour. Directions are model bearings from which the swell arrives.

Open-Meteo Marine API documentation, model coverage, and attribution.

Wind

10 m forecast

Wind speed and direction come from Open-Meteo’s Forecast API. Speed is converted from km/h to knots; the overview shows the 24-hour average speed and the direction at the first forecast hour. Wind directions describe where wind comes from; the map arrow is reversed to point toward travel.

Open-Meteo Forecast API documentation.

Tides & daylight

Important data note

The tide curve and high/low event labels are currently illustrative placeholders, not live tide predictions. They are not sourced from NOAA or Open-Meteo yet. Sunrise and sunset are fetched from Open-Meteo’s Forecast API.

Open-Meteo Forecast API documentation.

Map & fallback

Display and availability

The spot map is Google Maps’ standard road-map embed, used for geographic context only. If a forecast request fails, the affected spot can display generated demo values; its card and header identify that fallback as demo data.
